<analysis>**original_problem_statement**:
The user wants to build a large-scale, internal AI-powered workflow automation tool named FlowForge inside their existing company portal ().

PRODUCT REQUIREMENTS (FlowForge):
1.  **Conversational Interface**: Users build automations by describing problems in a chat interface using text and/or voice.
2.  **Duplicate Detection**: Before building, the system checks an inventory of all existing automations (including manually created ones on the automation engine) to prevent redundant work.
3.  **Integration Transparency**: The system identifies required service connections (e.g., Database, Email, Calendar), checks their availability, and asks for user confirmation before proceeding.
4.  **Admin Approval System**: All new tools and any modifications to existing tools must be submitted for approval to designated Unit Admins or Company Admins before deployment.
5.  **Persistent Conversations**: Every tool has a permanent, linked conversation history, allowing users to return anytime to view, troubleshoot, or request updates. The AI should have full context of the tool's history and status upon return.
6.  **White-Labeling**: The underlying technologies (n8n, Claude, Supabase) must be completely abstracted away from the end-user.
7.  **Platform Integration**: The feature must be seamlessly integrated into the existing React portal.
8.  **Technical Stack**: The project requires a new **Supabase (PostgreSQL)** database, integration with an **n8n** instance, and use of **Claude** and **Whisper** via the **Emergent LLM Key**.
